# Support

## Bug reports and feature requests

Open an issue on GitHub and pick the matching template:

https://github.com/pierreyvesdelion/rust-generator/issues/new/choose

Please search the [existing issues](https://github.com/pierreyvesdelion/rust-generator/issues) first.

## What to include in a bug report

- VS Code version
- Rust Generator version
- Operating system
- Steps to reproduce, expected and actual behavior
